# PCB source status

No custom PCB is part of this enclosure revision. The design uses purchased modules:

- Raspberry Pi 5
- Raspberry Pi Touch Display 2
- Camera module
- 1S USB-C charger/protection board
- 5 V boost/power-management board
- Audio amplifier
- Microphone module

Because there is no custom routed board, KiCad/EasyEDA project files and gerbers do not exist for this revision. If a custom power/audio board is designed later, add its source files here and commit the fabrication outputs as `gerbers.zip`.
